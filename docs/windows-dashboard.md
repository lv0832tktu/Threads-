# Windowsで管理画面を使う

Windows 10/11用です。就活・転職、AI、仕事術、お金、節約を扱い、毎日8:00・19:00・22:00（日本時間）に予約できます。この画面から実投稿やAPI取得は行いません。

## 1. 初回の準備

1. この変更のPRがmainにマージされた後、GitHubの「Code」→「Download ZIP」を押します。
2. ZIPを右クリックして「すべて展開」。ZIP内から直接起動しないでください。自分だけが使うフォルダに置き、OneDriveなど共有・同期フォルダを避けてください。
3. [Python公式サイト](https://www.python.org/downloads/windows/)からPython **3.12（64bit）**をインストールします。インストール時は「Add python.exe to PATH」とPython Launcherを有効にします。Pythonとライブラリの導入は無料です。
4. 展開したフォルダの `start_dashboard.bat` をダブルクリックします。初回はインターネット接続が必要です。無料のStreamlit・cryptography・Pillow・tzdataを専用フォルダへインストールします。管理者権限は不要です。
5. 黒い画面で暗号化キーを求められたら、GitHubの `THREADS_STATE_KEY` に登録した**同じキー**を貼り付けてEnter。文字は表示されず、ファイルにも保存しません。次回起動でも入力します。
6. 準備が終わるとブラウザが開きます。黒い画面は閉じずに残します。開かない場合は黒い画面の `http://127.0.0.1:...` をブラウザに入力します。

アクセストークンは不要です。GitHub Secretsは登録後に値を読み戻せません。暗号化キーを手元に保管していない場合は、復元方法を確認するまで操作を止めてください。既存履歴のキーを新しく作り直さないでください。キーをチャットやスクリーンショットで送らないでください。

## 2. 画面の操作

1. **はじめに**：「既存の暗号化状態を読み込む」を押します。復号エラーならキーを確認し、履歴を削除しないでください。
2. **競合登録**：自分で確認した公開投稿URL、テーマ、文字数、反応数を入力します。CSVでも登録できます。未確認の数値は空欄。URLの自動取得や本文コピーはしません。重複登録は追加されません。
3. **レポート・ChatGPT**：「最新の保存済みデータで週報を更新」。分析とプロンプトを確認・コピーしてChatGPT Plusへ貼り付け、翌週21本をJSONで作成します。実績がない場合は取得不可・仮説として表示されます。
4. **投稿案・承認**：JSONを選択し、翌週月曜と「通常文章21本」を選んで取り込みます。本文・根拠・日時を編集・確認し、確認チェックを入れて承認します。取り込み時点では未承認です。編集すると承認と予約が解除されます。
5. **予約・書き出し**：承認済み投稿を選んで予約します。8:00・19:00・22:00の予定を確認します。予約だけではThreadsへ公開されません。
6. **履歴・エラー**：保存済みの投稿履歴・実行状態を確認します。

GitHub側の実行環境へ移す方法は [運用手順](operations-dashboard.md) を参照してください。ローカル画面の変更が自動でGitHubへ同期されることはありません。今回、定期実行の有効化や実投稿はしません。

## 3. 終了・次回起動・トラブル

- 終了：黒い画面でCtrl+C。ブラウザも閉じます。次回は同じbatをダブルクリックします。起動時に必要ライブラリを確認し、既に導入済みなら再利用します。
- Pythonが見つからない：Python 3.12とLauncherをインストール後、batを起動し直します。
- インストール失敗：ネット接続・空き容量を確認。証明書検証を無効化しないでください。
- 二重起動しない：作業中の画面を終了してから起動し直します。競合ロックが出たら別の処理の終了を待ちます。
- `private` には未公開の本文などが保存されます。Gitでは除外されていますが、フォルダ全体や予約JSONを公開・他人へ共有しないでください。Windowsのファイル権限はユーザー用フォルダの設定で保護します。
- 更新時：上書きやフォルダ削除の前に、`private` と `state` を秘密のバックアップ先へ保存してください。新しいZIPにはローカルの下書きが入っていません。

Windows実機でのダブルクリック、ブラウザの起動、クリップボードからの秘密入力は初回に確認してください。開発環境はLinuxのため、実機の操作を代行して検証することはできません。
