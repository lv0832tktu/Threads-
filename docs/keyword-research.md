# 少量の公開キーワード調査

`config/keywords.json` は既存14分類を保持し、就活15語・転職13語・関連15語を追加しています。
同じ語は正規化して1つの検索対象にまとめ、複数分類への所属は残します。
初期状態は `enabled: false` です。この作業では実APIの呼び出しをしていません。

## 回数と頻度

日3リクエスト・ISO週20リクエスト、日本時間で集計します。1語最大2ページ、1ページ25件です。
2ページ取得すると2リクエストを消費します。APIエラーと結果0件は別の状態です。
失敗・中断・結果0件でも予約済み利用枠を消費し、同じ語は24時間以内に再検索しません。
全語を毎日検索せず、履歴のカーソルから順番に少量ずつ巡回します。
これらはローカルの制限であり、Metaの実際のAPI制限や取得結果を保証する値ではありません。

`analyze_keywords(client, config_path, history_path, output_path, now=None, persist=...)` は公式GETの
`keyword_search` だけを利用します。次ページURLを直接たどらず、検査したカーソルのみ利用します。
API呼び出し前に `private/keyword-history.json` の予約を保存し、`persist` コールバックを成功させます。
GitHub Actionsで使う場合、暗号化した状態の永続保存を行うコールバックを必ず指定してください。
デフォルトのコールバックはローカル検証用で、端末間・一時runner間の永続化を保証しません。
呼び出し側は共通ロック・Actions concurrencyによって排他的に実行します。
履歴は52日、分析は最近52実行まで保存します。

出力の `runs` には調査日時、語・分類、成功/失敗、返却件数、URL、文字数、フック分類、
APIが返した公開反応数のみを保存します。他者の本文・独立したユーザー名は保存しません。
URLには元の公開アカウント名が含まれます。APIが反応数を返さない場合は `null` とし、0に置換しません。
競合の閲覧数・非公開Insights・反応率を推測しません。検索サンプルは市場全体の流行ではありません。

## 公式APIの権限

公式資料 https://developers.facebook.com/docs/threads/keyword-search/ を参照し、
`threads_keyword_search` など現行の必要権限、アプリのアクセスレベル・レビュー状態を確認してください。
既存接続確認が成功しても公開検索権限の確認にはなりません。今回の追加コードの実接続は未検証です。
許可されないときはスクレイピングや非公式APIへ切り替えず、次の公開情報の手動入力を利用します。
新しい有料AI APIは利用しません。GitHub Actionsの実行料金が発生する可能性はあります。

## 公開情報の手動入力

ローカルJSONで、公開ページを自分で確認した観察だけを入力できます。

```json
{"observations":[{"url":"https://www.threads.net/@example/post/ABC",
"observed_at":"2026-10-09T19:00:00+09:00","theme":"就活",
"hook":"質問型","characters":120,"metrics":{"likes":3}}]}
```

`import_public_observations(source, target='private/manual-public-observations.json')` は既存観察を保持し、
URLと観察時刻が一致する観察を追加しません。フック分類は「質問型」「数字・手順型」「説明・体験型」です。
許可した項目だけを保存し、本文・ユーザー名・閲覧数は入力にあっても破棄します。
出典は `manual_public` と記録し、根拠を自動で検証済みとは扱いません。
個人情報・DM・非公開プロフィール・Secretsを入力しないでください。
生成した私的JSONを公開リポジトリへそのままコミットしないでください。
