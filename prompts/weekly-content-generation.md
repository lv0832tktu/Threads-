# 週21件のAI・仕事術・お金・節約投稿案を作成する指示

最初に添付した `reports/latest.md` または `latest.json` の対象期間・測定時刻・取得不可・少数データの注意を確認する。レポートがなければ成果を捏造せず、初回の検証案として作る。良かったテーマ、キーワード、構成、形式、時間帯を参考にし、継続するパターンと変更するパターンを分ける。競合の文章はコピーせず、出典URLを参考資料として扱う。

作成前に翌週月曜日の日付を確認する。AI初心者、忙しい社会人、家計や老後資金に不安がある読者を偏りなく扱う。AI活用、仕事の効率化、節約・家計・老後資金も組み合わせ、ジャンルはAI・仕事術・お金・節約の4つに限定し、各ジャンルを偏りなく扱う。就活・転職を新規の中心テーマにしない。架空の実体験・内定実績は作らず、実体験と一般論を明示する。金融・採用の個別結果を保証せず、不安をあおらない。

対象はAI活用、仕事の効率化、家計・資産形成・節約に関心がある日本の読者。専門家による個別助言のような断定、投資利益・収入上昇の保証、誇張を避ける。人間の承認前の下書きを作る。

JSON {"posts": [...]} 形式で21件を出力する。指定がなければ通常文章（post_type=text）21件とする。人間が混合形式を選んだ場合のみtext 7件、imageまたはcarouselを合わせて7件、thread 7件。id（安定した一意ID）、post_type、category、theme、keywords、text、approval_status="pending_approval"、approved=false を含める。本文と各スレッド項目は500文字以内。thread_itemsは3～7件の {"text":"..."}。image_urlsは公開HTTPS URL、imageは1件、carouselは2～20件。画像が未準備の場合はURLを捏造せず、その画像投稿を未完成として別記し、インポート可能と主張しない。alt_text、rights_confirmed=false を付ける。本人が権利確認するまで画像投稿を承認しない。

予定はAsia/Tokyoで7日分、text 08:00、image 19:00、thread 22:00。publish_datetimeはタイムゾーン付きISO形式。これは予定案であり、承認・予約操作を代替しない。話題・冒頭・構成の重複を避ける。フック、根拠を限定した本文、小さな行動や問いで締める。

数値・労働制度・金融・採用市場など検証が必要な主張には sources=[{"url":"実際に確認した公式URL","summary":"確認した根拠","confirmation_date":"YYYY-MM-DD"}] を付ける。未確認の出典、URL、日付を捏造しない。確認できない断定は削除または確認待ちとして明示する。投稿案の自動公開は禁止。

本文JSONと別に、画像7件以上について `image_prompts=[{"post_id":"対応ID","prompt":"作成指示","alt_text":"画像の説明","suggested_filename":"ID.png"}]` を出力する。小さい文字を詰め込まず、1枚1論点の図解・チェックリストにする。他者の画像を転載しない。画像は私がChatGPTで生成・確認し、公開URLを後から差し込む。

最後に21件を「日付・形式・テーマ・検証する仮説」の表で示す。通常文章7件、画像7件、ツリー7件を確認し、1ツリーは管理上1本と数える。各ツリーの最初の本文を `text` と `thread_items[0].text` の両方へ同一内容で設定する。各案は未承認で、予約は人間の承認後に別操作で行う。

画像のimage_sha256は実際の画像ファイル検証結果から人間が付ける。AIはハッシュを推測・捏造しない。未設定の画像は下書きとして取り込めるが、rights_confirmed=true と正しい画像ハッシュが揃うまで承認・公開できない。

通常文章だけで21本を作る場合も、毎日08:00・19:00・22:00に各1本。管理画面で「通常文章21本」を選び、全件未承認で取り込む。AI・仕事術・お金・節約を中心に、レポートの比較は仮説として扱う。
